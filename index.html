Integer Overflow Lab

Explore what happens when a program stores an arithmetic result in a fixed-width integer. Change the bit width and input values, then watch the binary representation and signed/unsigned interpretations change. This is a teaching simulation—not an exploit tool.

1. Choose the integer type

Try 8-bit values such as 120 + 20. The mathematical result is 140, but a signed 8-bit integer cannot represent 140.

2. What is stored?

140
140 mod 256 = 140
Unsigned interpretation: 140
Signed interpretation: -116

3. Look at the bits

Each cell is one bit. For signed integers, the leftmost bit is the sign bit.

Why does wrapping happen?

An n-bit unsigned integer has 2ⁿ possible bit patterns, representing 0 through 2ⁿ−1. Arithmetic outside that range wraps modulo 2ⁿ.

For signed two's-complement integers, half the patterns represent negative numbers. With 8 bits, the range is −128 through 127.
